# Presentation Template

To add a new presentation to Shop-Talks:
1. Copy this `_template` folder and rename it to your presentation's slug (e.g. `graphql-federation`).
2. Update `index.js` with your presentation title, category, event, and abstract.
3. Edit `slides.js` with your slides, bullet points, diagrams, and speaker notes.
4. Add the import to `src/presentations/index.js`.
5. That's it! Your talk will automatically appear in the showcase, filters, search, and slide player!
